# TPE-HoliPop (台北假日活動雷達)

專為台北生活圈打造的週末與國定假日快閃店、動漫展演、文創市集互動地圖。

- ⚡ **鎖定假日**：自動比對台灣行事曆，只篩選「週休二日」與「國定連假」活動。
- 🚫 **零促銷雜訊**：智慧過濾百貨週年慶、特賣會等促銷商業資訊。
- 🗺️ **暗黑質感地圖**：採用高對比 Esri Dark Canvas 底圖 + 自訂分類霓虹 Pin 與地標聚合。
- 🧭 **即時導航**：一鍵開啟 Google Maps 路線導航與大眾運輸規劃。
- 📦 **歷史編年歸檔**：每日定時排程抓取並保存日歷史快照與週彙整。

## 本地預覽

你可以使用任何靜態網頁伺服器開啟本專案：

```bash
# Python 內建伺服器
python -m http.server 8080

# 或使用 Node.js / npx serve
npx serve .
```

開啟瀏覽器前往 `http://localhost:8080` 即可預覽。

## 資料架構 (Data Architecture)

本專案採完整歷史歸檔模式，所有檔案皆為標準 GeoJSON `FeatureCollection` 格式：

```text
data/
├── events.geojson              # 【現役最新資料】前端地圖預設載入
├── 2026/                       # 【每日歷史快照】依年份歸檔
│   └── 2026-10-25.geojson
└── weekly/                     # 【每週滾動彙整】依 ISO 週數歸檔
    └── 2026-W43.geojson
```

後端定時排程每日自動採集雙北各公開展演資訊，完成去重、資料清洗與假日過濾後，自動發布更新。
